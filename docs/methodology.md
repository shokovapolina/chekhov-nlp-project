# Methodology

The workflow includes corpus conversion and preprocessing, descriptive statistics, morphological analysis, named entity recognition and Gephi network export, sentiment-model training on Russian tweets, sentiment analysis of the Chekhov corpus, MALLET topic modeling, and Word2Vec analysis.

The Gensim-MALLET notebook compares models with 8-10 topics using c_v coherence and saves an eight-topic model with 1,000 iterations.
