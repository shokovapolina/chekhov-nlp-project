# Results

This directory contains outputs produced by the notebooks.

- `corpus_statistics/` contains corpus-level frequency tables.
- `frequency_analysis/` contains BOW, bigram, and TF-IDF outputs.
- `morphological_analysis/` contains comparison outputs for models with and without punctuation.
- `ner_and_gephi/` contains named entity tables and Gephi graph files.
- `sentiment_analysis/` contains sentiment-analysis data and models.
- `topic_modeling/` contains MALLET CLI, Gensim-MALLET, saved models, and interpretation files.
- `voyant_tools/` contains the Markdown report based on the Voyant Tools analysis.
